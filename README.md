# Travellers

A static travel website built with HTML, CSS, Bootstrap and jQuery. It includes destination, discount, about, blog and contact pages.

## View locally

Clone this repository and open `index.html` in a browser, or run a local server from the repository root with Python 3:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000. Internet access is needed for the Bootstrap, jQuery and icon assets loaded from CDNs.

## Project layout

- `index.html`: home page.
- `destination.html`, `discount.html`, `about.html`, `blog.html`, `contact.html`: additional pages.
- `style.css` and `css/`: stylesheets.
- `images/`: image assets.

## Scope

This repository contains a frontend demonstration. Placeholder booking links and newsletter controls are not a complete booking or subscription service.
